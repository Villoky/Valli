# DaVinci Resolve Studio: MCP

Проверено 2026-10-17: нативный MCP-сервер появился в Resolve **Studio 21.1** (сентябрь 2026), поддерживает Claude, Claude Code и Codex. В бесплатной версии MCP нет, Python-скриптинг с 21.1 тоже только в Studio.

## Подключение

**Claude Code (Mac):**
```
claude mcp add "DaVinci Resolve" -- "/Applications/DaVinci Resolve/DaVinci Resolve.app/Contents/Applications/ResolveMCP"
```
На Windows путь к `ResolveMCP` — внутри папки установки Resolve; найди его поиском по имени файла.

**Приложение Claude:** готовое расширение `DaVinciResolve.mcpb` лежит в `Contents/Resources` программы. Либо в Resolve: File → Setup AI Assistants и дальше по подсказкам.

Открывать Resolve заранее не нужно — агент запустит его сам.

## Инструменты MCP
- запустить Resolve и проверить, что он работает;
- выполнить скрипт через Python API Resolve;
- найти функцию в документации API;
- создать и поправить LUT и DCTL.

Через скрипты доступно почти всё из API: проекты и таймлайны, импорт, раскладка клипов по дорожкам с точностью до кадра, маркеры, субтитры из звука, трансформ кадра, переходы, выравнивание громкости, рендер.

## Чего не умеет
- **Смотреть видео.** Рендерит кусок и проверяет по кадрам.
- **Оформлять встроенные субтитры и менять длину титров** — в API этого нет. Титры делай отдельной анимацией (HyperFrames).
- **Плавное появление и исчезновение плашки** — вшивай fade в сам файл плашки.

## Подводные камни (проверено рендером)

| Что | Последствие | Решение |
|---|---|---|
| PNG на таймлайне дольше 5 с | Скрипт молча обрезает до 5 с | Перегнать плашку в MOV нужной длины |
| Эффекты Fusion, добавленные скриптом | В рендер не попадают | Размытый фон и т.п. — отдельным файлом |
| Выключение дорожки скриптом | На рендер не влияет | Версию без дорожки — отдельным таймлайном |
| Клипы с разной частотой кадров | Дырка в 1 кадр на стыке | Всё к одной частоте; проверять стыки после сборки |
| 7 видеодорожек | Рендер падал на 50% | Видеоряд одним куском, ≤3 слоя |
| Сдвиг кадра скриптом | Лицо прыгает одним рывком | Заранее отрендерить лицо с плавным переездом |
| Звук вставки | DaVinci иногда теряет звуковую дорожку | В финальном проходе проверять громкость вставок, подкладывать звук из файла |

## Что пропускает ИИ (кейс «Ночной город»)
Пять вещей, которые заметил бы монтажёр: тёмный кадр; поезд дважды; улица дважды; один и тот же город сверху трижды; витрина почти в 3 раза ярче соседних кадров. Отсюда обязательный пункт проверки: повторы планов и скачки яркости между соседними клипами.
