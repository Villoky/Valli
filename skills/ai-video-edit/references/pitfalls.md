# Брак сборки: причина → решение

Пройди список до того, как показывать ролик пользователю.

| Что видно | Почему | Как исправить |
|---|---|---|
| Плашка пропадает резко, за 1 кадр | DaVinci через скрипт не делает fade | Вшить появление 0,15 с и исчезновение 0,3 с прямо в файл плашки |
| Лицо прыгает вбок, когда появляется плашка | Скрипт сдвигает кадр одним рывком | Заранее отрендерить лицо с плавным сдвигом 0,5 с, начинающимся чуть раньше плашки |
| Слева пустая полоса, когда одна плашка ушла, а следующая не пришла | Тень была частью каждой плашки | Вынести тень на отдельную сплошную дорожку V2 |
| Между вставками мелькает 1 кадр лица | Округление времени даёт зазор 1–2 кадра | Продлевать предыдущую вставку до следующей, если зазор < 0,5 с |
| Вставка начинается с пустого тёмного кадра | В первых кадрах анимации ещё ничего нет | Брать вставку с 0,3 с |
| Чёрный кадр перед вставкой или заставкой | Первый кадр файла чёрный | Срезать первые кадры или начинать с 0,2 с |
| У вставки пропал звук | DaVinci потерял звуковую дорожку | В финальном проходе проверять громкость вставок, подкладывать звук из файла |
| Вставка со своей музыкой громче голоса | У неё своя громкость | Замерить и опустить до уровня голоса |
| Квадратный ролик на весь экран, по бокам видно лицо | Лицо лежит под вставкой | Подложить светлую подложку цвета фона ролика |
| Запись обрывается на полуслове, затухание резкое | Ролик кончается на последнем кадре файла | +2 с: задержать последний кадр, плавно погасить картинку и звук |
| Лист кадров смотрели с шагом 2 с, брак проскочил | Ошибки на стыках длятся 1 кадр | Стыки — скриптом, чёрные кадры — `blackdetect`, а не только глазами |
| Дырка в 1 кадр на стыке | Разная частота кадров | Привести всё к одной частоте |

## Брак анимаций

| Проблема | Решение |
|---|---|
| Линия с круглыми концами рисует точку до начала прорисовки | Прятать линию, пока она не пошла |
| Обрезка срезает хвосты рукописных букв | Запас у элемента, на котором стоит обрезка |
| Цифры двоятся при motion blur | Менять цифру ровно на границе кадра |
| Фон чёрный поверх видео | MP4 без альфы → MOV ProRes 4444 |
| Пустая половина плана, кривая финальная плашка | Лист кадров глазами + субагент до сдачи |

## Проверка чёрных кадров
```
ffmpeg -i ролик.mp4 -vf "blackdetect=d=0.03:pix_th=0.10" -an -f null - 2>&1 | grep black_start
```
`d=0.03` ловит одиночный кадр при 25–30 fps.
